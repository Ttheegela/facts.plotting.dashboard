# v1.0 — Initial Release

**Script:** [`facts_dashboard.py`](../../facts_dashboard.py)

## Features
- 6 independent line slots (workflow × SSP × component × scale × location)
- Uncertainty bands: p17–p83 shading, p50 median line
- Component breakdown table (rows = components, cols = SSPs)
- 24 Indian Ocean tide gauge locations
- Global Mean SL and Local RSL toggle
- X/Y range sliders, show/hide checkboxes per line slot
- Workflow reference table (Kopp et al. 2023, Table 2)
